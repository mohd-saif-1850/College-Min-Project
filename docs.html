AUTHENTICATION

Authenticate your requests

Every API request must include a valid Mail Service API key. API keys identify your project and authorize requests to the service.

Authorization
Copy 
Authorization: Bearer YOUR_API_KEY
Keep your API key private.

Never expose your API key in client-side code, public repositories, browser applications, or frontend JavaScript.

03
OUR API

Your Mail Service API

The Mail Service API provides a simple HTTP interface for sending emails from your application.

POST
https://mailservice.com/send-emails/YOUR_API_KEY
Copy
Base endpoint

Replace YOUR_API_KEY with the API key associated with your Mail Service project.

Method POST
Authentication API Key
Content-Type application/json
Response JSON
04
SEND EMAIL

Send an email

Make a POST request to the Mail Service endpoint with the recipient, subject, and content of your message.

Request
JavaScript 
const response = await fetch(
    "https://mailservice.com/send-emails/YOUR_API_KEY",
    {
        method: "POST",
        headers: {
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            to: "user@example.com",
            subject: "Welcome to Mail Service",
            text: "Thanks for joining us."
        })
    }
);

Request body

Parameter Type Required Description
to string Yes Recipient email address.
subject string Yes Subject of the email.
text string Yes Plain-text email content.
html string No HTML version of the email.

Response

202 Accepted
JSON 
{
    "success": true,
    "messageId": "msg_8f92a1",
    "status": "accepted"
}

06
DELIVERY

Understand delivery states

Every email moves through a delivery lifecycle. Use these states to understand what happened to your messages.

✓
Accepted

Mail Service accepted the request for processing.

•
Processing

The message is currently being processed.

✓
Delivered

The message was successfully delivered.

!
Failed

Delivery could not be completed.

07
ERRORS

API errors

When a request cannot be processed, the API returns a structured JSON response with an appropriate HTTP status code.

Status Meaning Action
400 Invalid request

Check the request body and parameters.

401 Unauthorized

Check your API key.

403 Forbidden

Verify your project permissions.

429 Rate limited

Slow down requests and retry later.

500 Server error

Retry the request or check system status.
